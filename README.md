## ✨ Features
- **Modern UI/UX:** Clean and minimal design with smooth animations.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
- **Project Showcase:** A dedicated section to display my latest open-source work and applications.
- **Contact Integration:** Easy-to-use contact links and social media integration.

## 🛠️ Local Development Setup

To run this portfolio locally on your machine, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/varunvamin/varun_portofolio.git
   ```
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Start the development server**
   ```bash
   npm run dev
   # or npm start
   ```
4. **Open in Browser**
   Navigate to `http://localhost:3000` to view the site.
